# Color Normalization Comparison

## 概要
このリポジトリでは、毒性病理画像を潜在表現に変換した際に残る施設間差・スライド間差を染色正規化でどの程度排除できるのかを検討するものです。
特に、どの染色正規化手法が最も効果的であるかを比較することを目的としています。

## 方針
WSIをUNIを用いて潜在表現に変換する。その際のツールとしてはTRIDENTを活用する。
変換の前に、Macenko, Reinhard, Vahadaneの3つの染色正規化手法を用いてWSIを正規化する。
これらと、何も正規化を行っていない潜在表現に対して、η-squaredを用いて施設間差・スライド間差を定量的に評価する。
併せて、バッチ効果の除去が生物学的シグナルまで壊していないかを見るためのタスク有用性チェック(has_finding検出力)と、
スライドごとの混ざり方を目で見るための2次元可視化(t-SNE)も行う。

## データセット
TG-GATEsから取得したWSI998枚(`data/raw_slide`)を使用する。
施設間差・スライド間差やぼやけの影響が大きいことが確認されているので改善すれば今後の活用に非常に役立つと思っている。
Open TG-GATEsには本当の意味での「施設(病院)」列が存在しないため、EXP_ID(化合物投与実験のバッチID、998スライド中261種)を
「施設間差」相当のグループラベルとして使っている。「スライド間差」はslide_id(.svsファイル名)そのもの。

## やったこと
4つの実験フェーズに分けて実装・実行した(詳細は [`EXPERIMENT_NOTES.md`](./EXPERIMENT_NOTES.md) 参照)。

1. **`0001_extract_tissue_coords`**: TRIDENTで998枚を組織セグメンテーション+パッチ座標抽出し、スライドあたり500パッチへ決定的にサブサンプル。
2. **`0002_extract_uni_features_by_normalization`**: none/Macenko/Reinhard/Vahadaneの4条件でUNI特徴量を抽出。TRIDENTには染色正規化のフックが無いため、UNIエンコーダの前処理パイプライン(`eval_transforms`)に正規化処理をラップして注入し、4条件とも同一のパッチ座標を使って比較できるようにした。
3. **`0003_compare_stain_normalization_batch_effect`**: η-squared(施設間差・スライド間差)とKNN分類精度で4手法のバッチ効果除去度を比較。
4. **`0004_evaluate_finding_utility_and_visualize`**: η-squaredだけでは「バッチ情報が消えた」のか「情報ごと潰れた」のか区別できないため追加。has_finding(病理所見の有無)へのロジスティック回帰プローブのAUROCで生物学的シグナルの保持度を確認し、t-SNEでスライドごとの色分け散布図を作成。

## 結論

**Macenkoが最もバランスの取れた選択という結果になった。** 4手法の比較は以下の通り(値は全て単一run・点推定、信頼区間は未算出):

| method | η²施設間差↓ | η²スライド間差↓ | KNN施設間差↓ | KNNスライド間差↓ | has_finding AUROC↑ |
|---|---|---|---|---|---|
| none | 0.201 | 0.289 | 0.498 | 0.507 | 0.774 |
| **macenko** | **0.180** | **0.260** | **0.259** | **0.282** | 0.798 |
| reinhard | 0.219 | 0.312 | 0.317 | 0.369 | **0.813** |
| vahadane | 0.187 | 0.269 | 0.266 | 0.299 | 0.788 |

- **バッチ効果除去はMacenkoが最良**。η²の差は手法間で小さいが、KNN分類精度(パッチからスライド/施設を当てられる精度)では明確な差が出ており、無正規化なら約50%当てられてしまうのに対しMacenko適用後は約26〜28%まで下がる。
- **Reinhardだけはバッチ効果が無正規化より悪化**する一方、has_finding検出力は4手法中最も高い。これはReinhardの正規化がバッチ由来の色差と病理所見由来の染色強度差を区別せず両方強調している可能性を示唆しており、「バッチ効果を消せている」とは言いにくい。
- Macenkoはバッチ効果削減で1位、has_finding利用性でも2位(無正規化より明確に改善)と、両立度で見て最も無難な選択。
- t-SNE可視化では、4手法間の見た目の差はKNN精度の差ほど明確ではなかった(どの条件でもスライドの色はある程度混ざっており、劇的な「塊→混合」の変化は視覚的には確認しづらい)。定量指標の方が判断材料として頼りになる。

**留意点**: 「施設間差」はEXP_ID(化合物投与実験バッチ)を代理指標として使っており、真の意味での施設(スキャナ・病院)差ではない。また評価はスライドあたり500パッチのサブサンプル・単一シードでの点推定であり、信頼区間や手法間差の有意性は未検証。
